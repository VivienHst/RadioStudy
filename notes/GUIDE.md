# 學習筆記寫法

每集一個檔案：`notes/<節目代號>/<集數>.json`，格式見 README。這份文件說明**挑哪些詞、怎麼寫**。讀者是用繁體中文準備日檢的人，邊看逐字稿邊學。

## 輸入

那一集的 `subs.ja.srt`（日文，已修正過 Whisper 錯字）和 `subs.zh-hant.srt`（中文翻譯），在 SubtitleExtension 的 `temp/<集數資料夾>/`。兩個檔案的字幕編號一一對應，筆記裡的 `line` 就是這個編號。

整集讀完再挑詞，不要只看前半。

## 挑什麼

**單字（vocab）**：大約 100–170 個，依該集內容多寡增減。
- N1–N3 的詞盡量收齊；N4・N5 只收學習者容易忽略或用法特別的詞，不收 する、いる、私、今日 這種基本詞。
- **不收已經在其他集筆記裡的詞**（網站會自動在每一集標出它們）。`check_notes.py` 會用 warning 列出重複的詞，刪掉即可；只有讀音或意思明顯不同時才保留。
- 不收人名、地名、節目名、團體名。
- 外來語只收和製英語或意思跟英文不同的（テンション、ハマる），一般外來語不收。
- 字幕本身辨識錯的地方不要拿來當例句；真的要收，在 `note` 寫明「字幕辨識成「X」，應為「Y」」。

**文法（grammar）**：15–25 個句型，`term` 用「～」表示接續位置（～わけじゃない、～ことになる）。口語縮約形放在 `note` 說明標準形。

**慣用句（idioms）**：5–12 個固定說法（気合いが入る、灯台下暗し），`reading` 是整句的平假名。

**擬聲擬態語（onomatopoeia）**：5–10 個（ギスギス、ペロッと），照字幕寫法。

**提醒（tips）**：1–3 張，寫這集口語的特徵（ら抜き、縮約、方言、敬語用法），每張一個 `title` 和幾個 `items`。items 可用 `**粗體**`、`` `mm:ss` `` 時間、`<br>` 換行。

## 欄位

| 欄位 | 寫法 |
|---|---|
| `term` | 辭書形（動詞原形、形容詞原形）。 |
| `reading` | 平假名；片假名詞照寫片假名。要是**這一集裡的讀法**。 |
| `pos` | 名、名・する、動五、動上一、動下一、動カ、動サ、い形、な形、副、連語、接尾、感 等，可用「・」組合（名・な）。單字都要寫。 |
| `level` | 只能是 `N1`、`N2`、`N3`、`N4-5`。文法也一樣，不要寫 `N4`。 |
| `meaning` | 繁體中文、台灣用語，簡短，多個意思用「、」分隔，例如「心浮氣躁、飄飄然」。 |
| `note` | 選填，一句話：反義詞、常見搭配、口語↔標準形、字幕錯字。 |
| `line` | 例句所在的字幕編號，挑最能看出意思的一句。 |
| `form` | 例句裡**實際出現的字串**（活用後的形式，連 Whisper 的寫法都照抄），網站用它在逐字稿標示。 |
| `to` | 例句跨行時才寫，最後一行的編號，最多 `line + 2`。 |

`reading` 也會拿來幫**全站**同樣寫法的字加振假名。同一個寫法有好幾種常見讀音的詞（人気 にんき／ひとけ、上手 じょうず／うわて、一日、今日、大家、生、方），收的時候要確定這集的讀法，並在回報時列出來。

## 檢查

```
python tools/check_notes.py notes/rikosaka/124.json --format
```

改到 0 errors 為止。`--format` 會在通過後把檔案整理成一行一個項目。只改自己負責的那一集，不要跑 `tools/build.py`。
